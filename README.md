# Song Auto Detail

First-pass static rebuild of [songautodetail.com](https://www.songautodetail.com), hosted on GitHub Pages.

Demo: https://ryazlee.github.io/song-auto-detail-site/

See [OVERVIEW.md](./OVERVIEW.md) for architecture.

```bash
npm install
npm run dev
```

Production build is a static export (`out/`) with `basePath` `/song-auto-detail-site` when `GITHUB_PAGES=true`.
